# DeFi Zero-Cost Lab: APR/APY & Impermanent Loss Simulator
## Deskripsi Proyek
DeFi Zero-Cost Lab merupakan proyek pembelajaran teknologi blockchain yang berfokus pada eksplorasi Decentralized Finance (DeFi) menggunakan simulasi Python tanpa modal nyata.
Proyek ini dibuat sebagai bagian dari praktikum Teknologi Blockchain untuk memahami mekanisme keuntungan, perhitungan return, dan risiko dalam ekosistem DeFi.
## Tujuan
1. Memahami konsep dasar Decentralized Finance.
2. Menghitung APR dan APY menggunakan Python.
3. Melakukan simulasi keuntungan Lending, Staking, Liquidity Providing, dan Yield Farming.
4. Menganalisis Impermanent Loss melalui perbandingan HODL dan Liquidity Providing.
5. Mengidentifikasi risiko serta peluang blockchain yang dapat dipelajari tanpa modal.
## Materi Proyek
- Blockchain dan Smart Contract

- Lending dan Staking
- Yield Farming
- APR vs APY
- Impermanent Loss

## Metode Pengerjaan
Proyek ini menggunakan pendekatan simulasi berbasis Python dengan data dan modal virtual. Hasil eksperimen digunakan untuk membandingkan mekanisme return dan menganalisis risiko yang mungkin muncul dalam aktivitas DeFi.
## Keamanan
Seluruh simulasi menggunakan uang virtual. Proyek ini tidak melibatkan pembelian cryptocurrency, deposit, trading, maupun penggunaan aset kripto nyata. Tidak ada private key atau seed phrase yang disimpan dalam repository.
## Hasil yang Diharapkan
Proyek ini menghasilkan notebook edukasi, tabel perhitungan, visualisasi grafik, analisis risiko, dan dokumentasi yang dapat digunakan sebagai bukti pembelajaran serta portfolio di bidang Blockchain dan DeFi.
